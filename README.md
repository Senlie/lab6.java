Завдання:
- створити ієрархію квітів (абстрактний клас + 3 нащадки)
- зібрати букет з аксесуарами та підрахувати вартість
- відсортувати квіти за рівнем свіжості
- знайти квітки за заданим діапазоном довжини стебла

---

## Що і як зроблено

1. Створено абстрактний клас `Flower` з полями `name`, `price`, `stemLength`, `freshnessLevel` та абстрактним методом `getAroma()`.
2. Створено 3 класи-нащадки: `Rose` (+ колір), `Tulip` (+ форма пелюстків), `Lily` (+ кількість бутонів). Кожен перевизначає `getAroma()` і `toString()`.
3. Створено клас `Accessory` для аксесуарів букета.
4. Створено клас `Bouquet` з масивом `Flower[]` та `Accessory[]`, методами:
   - `getTotalPrice()` — загальна вартість
   - `sortByFreshness()` — сортування за свіжістю через `Arrays.sort` + `Comparator`
   - `findByLengthRange(min, max)` — пошук квіток за діапазоном довжини стебла
5. Оброблено виключні ситуації: `NullPointerException`, `IllegalArgumentException`, `Exception`.
